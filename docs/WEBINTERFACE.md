# Webinterface

De webinterface is bereikbaar via:

```text
http://192.168.2.27:8080/
```

## Tabbladen

### Status
Toont de actieve bron, playerstatus, uptime, configuratiepad en basisstatus van PiViewer.

### WiFi / Network
Toont netwerk- en WiFi-status, scant beschikbare WiFi-netwerken en kan een verbinding maken met SSID en wachtwoord.

### Stream
Beheer van de hoofdstream en geplande streams. Hier kun je de HLS-hoofdstream aanpassen en streams programmeren met dagen, uren, maanden en herhaling.

## JSON
De JSON-link blijft beschikbaar als technische controlepagina voor de actuele configuratie.
