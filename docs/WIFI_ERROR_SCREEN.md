# WiFi foutmelding op scherm

Vanaf PiViewer 2015 zit `nossid.png` vast in de applicatie onder `/opt/piviewer-dev/assets/nossid.png`.

Deze afbeelding staat dus niet op de USB-stick en wordt ook niet meegenomen in de normale USB Photo Viewer.

Als een stream internet nodig heeft maar WiFi/netwerk niet beschikbaar is, toont PiViewer deze afbeelding fullscreen. Zodra netwerk/internet terug is, schakelt PiViewer terug naar de actieve planning of hoofdstream.
