# USB Auto Update

Plaats een hogere update-ZIP op de USB-stick, bijvoorbeeld:

```text
PiViewer_2020.zip
```

Vanaf PiViewer 2020 wordt het updatevenster direct op het HDMI-scherm getoond zodra PiViewer een hogere versie op USB ziet. De actieve stream of slideshow wordt eerst gestopt zodat het updatevenster niet pas kort aan het einde zichtbaar wordt.

Na de update herstart PiViewer de service schoon.
